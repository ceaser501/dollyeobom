# 돌려봄 (dollyeobom)

> 학습지를 찍으면, 3D로 돌려보며 이해한다.

초등학생이 입체도형 문제에서 막혔을 때 문제를 사진으로 찍어 올리면,
AI가 문제를 해석해 **3D로 렌더링**하고 **단계별 해설**을 보여주는 학습 서비스입니다.
푼 문제는 교육과정 태그와 함께 히스토리로 쌓이고, 어떤 단원·유형이 약한지 리포트로 알려줍니다.

## 범위 (1단계: 초등)

| 단원군 | 3D로 보여줄 것 |
|---|---|
| 여러 가지 모양 (상자·둥근기둥·공) | 입체 모양 회전, 분류 |
| 쌓기나무 | 블록 개수, 위치, 위·앞·옆 모양 |
| 직육면체·정육면체 | 겨냥도, 보이지 않는 모서리, **전개도 접기/펼치기** |
| 각기둥·각뿔 | 구성 요소, 전개도 |
| 직육면체의 부피·겉넓이 | 단위 정육면체 채우기, 겉면 펼치기 |
| 원기둥·원뿔·구 | 돌려 만든 입체, 원기둥 전개도 |

이후 확장: 중학교 입체도형 → 취업 준비 대학생 공간지각(인적성).

## 동작 흐름

```
① 사진 촬영/업로드
② 비전 LLM이 문제 해석 → "이렇게 이해했어요" 확인/수정
③ 장면 JSON 생성 (docs/scene-schema.md)
④ Three.js로 3D 렌더링 → 마우스/터치로 회전·확대
⑤ 단계별 해설 (3D 화면과 연동: 강조, 시점 이동, 접기 애니메이션)
⑥ 교육과정 태그와 함께 히스토리 저장 → 약점 리포트
```

핵심 원칙: **이미지→3D 생성 AI를 쓰지 않는다.** AI는 문제를 이해해 "어떤 도형을 어떤 치수로 둘지"만 정하고,
그리는 일은 미리 만든 도형 템플릿이 맡는다.

## 기술 스택 (예정)

| 역할 | 선택 |
|---|---|
| 프론트엔드 | Vite + React (모바일 웹 우선) |
| 3D | three.js + react-three-fiber + drei |
| 백엔드/DB/인증/스토리지 | Supabase |
| 문제 해석·해설 | 비전 LLM API (JSON 출력 강제) |

## 개발 단계

1. **태그 체계** — 초등 입체 단원 × 문제유형 표 확정, 성취기준 코드 매핑 → `docs/curriculum-tags.md`, `data/curriculum-tags.csv`
2. **검증 스파이크** — 실제 문제 사진 30~50장으로 사진→JSON 정확도 측정 → `docs/validation-plan.md`
3. **3D 렌더러** — 쌓기나무 → 직육면체 전개도 → 각기둥·각뿔 → 원기둥·원뿔·구
4. **MVP 앱** — 촬영 → 확인 → 3D·해설 → 히스토리
5. **리포트** — 태그별 약점, 주간 리포트(학부모 공유), 자체 제작 유사 문제

## 프로토타입 실행

```bash
cd web && npm install && npm run dev
```

예시 문제는 API 키 없이 바로 볼 수 있다. 사진 해석 서버 연결은 [docs/setup-supabase.md](docs/setup-supabase.md) 참고.

| 폴더 | 내용 |
|---|---|
| `web/` | 화면 (Vite + React + react-three-fiber). 2D/3D 보기, 단계별 해설, 다시 풀기 |
| `supabase/functions/analyze-problem/` | 사진 → 장면 JSON (Claude API, 키는 서버에만) |
| `supabase/migrations/` | 하루 사용량 제한 |
| `scripts/gen-tags.mjs` | `data/curriculum-tags.csv` → 태그 모듈 생성 |
