# 검증 계획: 사진 → 장면 JSON 정확도

앱을 만들기 전에 **"비전 LLM이 초등 입체 문제 사진을 제대로 구조화하는가"** 를 먼저 확인한다.
이 서비스에서 가장 불확실한 부분이 여기다.

## 1. 샘플 수집 (30~50장)

구글 이미지와 블로그·카페 게시글에서 수집한다.

### 검색 키워드

| 단원군 | 키워드 |
|---|---|
| 쌓기나무 | `쌓기나무 문제`, `쌓기나무 개수 세기`, `쌓기나무 위 앞 옆 모양` |
| 직육면체 | `직육면체 겨냥도 문제`, `정육면체 전개도 찾기`, `직육면체 전개도 문제` |
| 각기둥·각뿔 | `각기둥 전개도 문제`, `각뿔 구성요소 문제` |
| 부피·겉넓이 | `직육면체 겉넓이 문제`, `직육면체 부피 쌓기나무` |
| 공간과 입체 | `초6 공간과 입체 문제`, `위에서 본 모양 수 쓰기` |
| 원기둥·원뿔·구 | `원기둥 전개도 문제`, `돌려 만든 입체 문제` |
| 공통 | `수학익힘 6-2 풀이`, `숙제 인증 수학 입체` (실제 휴대폰 촬영본이 많음) |

### 구성 비율

| 종류 | 목표 |
|---|---|
| 휴대폰 촬영본 (기울어짐, 그림자, 손글씨) | 50% 이상 |
| 깨끗한 스캔본·교재 이미지 | 30% |
| 필기·답 표시가 덮인 사진 | 10~20% |

단원군마다 최소 4장 이상 모은다.

### 보관 규칙

- 수집 이미지는 **저작권 때문에 저장소에 커밋하지 않는다.** `samples/images/`에 두고 `.gitignore`로 제외한다.
- 출처 URL만 `samples/answer-key.csv`에 기록한다.
- 내부 테스트용으로만 쓰고, 서비스 화면이나 학습 데이터로 쓰지 않는다.

## 2. 정답표

`samples/answer-key.csv` (양식: [`samples/answer-key.template.csv`](../samples/answer-key.template.csv))

| 컬럼 | 예시 |
|---|---|
| `sample_id` | `S001` |
| `file` | `S001.jpg` |
| `source_url` | 원본 링크 |
| `photo_kind` | `phone` / `scan` / `annotated` |
| `tag_id` | `E6-SPACE-VIEWS-TO-COUNT` |
| `scene_type` | `blocks` |
| `scene_truth` | 핵심 구조 요약 (예: 블록 좌표, 전개도 면 배치) |
| `answer` | `4` |
| `notes` | 정답이 여러 개 가능 등 |

## 3. 실행

1. 프롬프트 = 시스템 지시 + 태그 목록(csv) + 장면 형식(`docs/scene-schema.md`) + 사진
2. 출력을 JSON으로 강제하고, 스키마 검증에 실패하면 실패로 기록한다
3. 사진마다 3회 실행해서 결과가 일관적인지 본다
4. 결과는 `results/<날짜>/<sample_id>.json`에 저장한다

## 4. 평가 지표

| 지표 | 정의 | 합격 기준 |
|---|---|---|
| JSON 유효율 | 스키마 검증 통과 비율 | 98% 이상 |
| 태그 정확도 | `tag_id` 일치 (단원군만 맞으면 부분 점수) | 90% 이상 |
| **장면 구조 정확도** | 블록 좌표·전개도 배치·치수가 정답표와 일치 | **80~90% 이상** |
| 정답 정확도 | `answer` 일치 | 90% 이상 |
| 해설 품질 | 사람이 5점 척도로 평가 (정확성, 초등 눈높이) | 평균 4점 이상 |
| 자기 인지 | 틀린 결과에서 `confidence`가 낮거나 `unclear`를 채웠는지 | 참고 지표 |

장면 타입별, 사진 종류별로 나눠서 본다 (예: "휴대폰 촬영 쌓기나무만 정확도가 낮다").

## 5. 결과에 따른 판단

| 결과 | 다음 행동 |
|---|---|
| 합격 | 3D 렌더러 개발로 진행 |
| 특정 타입만 낮음 | 해당 타입은 확인 단계를 강화하거나 MVP 범위에서 제외 |
| 전반적으로 낮음 | 프롬프트·스키마 단순화, 촬영 가이드(정면·밝게·한 문제만) 추가 후 재측정 |
| 다른 모델이 더 나음 | 모델별 비교표를 남기고 선택 |
